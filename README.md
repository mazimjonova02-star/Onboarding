## Практика и производительность

- CoinShop удалён со слайдов 5 и 6; на слайде 4 сохранён.
- Быстрые ссылки используют существующие иллюстрации вместо контурных значков.
- Первый лабиринт сохранён. На втором и третьем добавлены альтернативные проходы, прыжки доступны на всех уровнях. Для победы достаточно портала; монеты и короткое решение через REPEAT — бонусные задачи. Ограничения очереди 24/32 блока защищают от случайного переполнения, а не требуют единственного решения. Через каменные стены прыгать нельзя.
- При контакте с Крипером Стив возвращается на старт, монеты сбрасываются, программа сохраняется для исправления. Правила показаны над полем.
- Стив плавно исчезает внутри портала, сам портал остаётся. Затем появляется поздравление; через 4 секунды начинается плавный переход дальше. На третьем уровне итог остаётся до выбора ученика. Смена уровня, вкладки или очистка отменяет отложенные переходы.
- Тема меняет преимущественно светлый фон и основную кнопку. Фотографии сохраняют исходные цвета без смешивания и цветных фильтров; карточки белые, значки и полосы опыта разноцветные. Добавлены слоган, три идеи проектов, скругления и шаг повышения уровня.
- Стрелки при вводе не переключают слайд. Таймер игры останавливается при уходе со слайда/скрытии страницы, очистка также останавливает выполнение. Анимации скрытых окон/страницы приостанавливаются. Аудиоузлы отключаются после воспроизведения.
- Шрифты и библиотека салюта больше не блокируют основной интерфейс при загрузке. URL локальных CSS/JS получили версию против старого кэша. Исправлены буквальный тег h1 в подсказке и недопустимое учебное значение box-shadow (neon).
- Файлы: около 11,4 МиБ. Оценка RGBA всех статичных изображений: 72,7 МиБ при полной декодировке. Замер Chrome Performance.getMetrics после игровых проверок: JSHeapUsedSize 7 557 708 байт, около 7,2 МиБ. Это не вся память вкладки: изображения, GPU и расходы браузера учитываются отдельно. Расход в гигабайтах не установлен.
- Проверено в текущем Chrome; компьютеры преподавателей и остальные браузеры отдельно не проверялись. Публикация Vercel: 28 октября 2026 года, deployment dpl_APUNnuy5A3g3mbtR27NGQ7iZgdmy (READY). Проверены рабочая ссылка, версия portal3, отсутствие не загруженных видимых изображений и исходные цвета фотографий.

Проверки логики: `node tests/practice-regression.cjs` выполняет настоящий `script.js` с управляемыми таймерами: Крипер, сохранение программы, независимый портал, поздравление перед переходом, альтернативное решение без всех монет, доступные прыжки, отмена переходов и финал третьего уровня. ## Переходы между слайдами
- `transitions.js` + `transitions.css`. `goToSlide` в `script.js` вызывает `JuniorFx.run`, сама смена слайда — `applySlide`.
- Три облачных варианта, все двигают настоящее небо на фоне (`.sky-bg`, `.sky-strip`, `.sky-cloud`):
  - `fly` «Полёт» — небо приближается, облака вылетают из центра мимо «камеры», слайд размывается и появляется из глубины; «Назад» — наоборот.
  - `rise` «Подъём» — слои облаков уходят вниз с параллаксом, облака пролетают сверху вниз, новый слайд опускается сверху с лёгким пружинным отскоком.
  - `wind` «Ветер» — облака на фоне разгоняются (playbackRate CSS-анимаций), линии ветра, слайд уносит как листок, новый прилетает с другой стороны.
- Тихий «вжух» синтезируется Web Audio, только если звук на сайте включён.
- Временная панель выбора `#fx-pick` (внизу слева) — выбор сохраняется в localStorage; убрать: `SHOW_PICKER = false`.
- Отключено при `prefers-reduced-motion`, в фоновой вкладке и при первом показе. Быстрые клики не ломают порядок.

## Слайд 6 «Острова» (заменил практику)
- `island-slide.css` + `island-game.js`; картинки `images/ui/island-{web,math,english}.webp` (WebP, ~50 КБ каждая).
- Три парящих острова: программирование, математика, английский. Нажатие на остров = «полёт» камеры (переход `fly` из `transitions.js`) и игра из 3 заданий. Острова из выбора на слайде 2 помечены «Твой выбор», остальные тоже доступны.
- Сложность берётся из возраста (`html[data-lesson-age]`: kids / juniors / teens): 3 острова × 3 возраста × 3 задания = 27 заданий (данные в `DATA`, `window.JuniorIslandData`). Типы: выбор ответа, «собери предложение», «расставь команды роботу».
- Ошибиться нельзя: первая ошибка — подсказка, вторая — робот решает вместе. Без таймера и оценок. После 3 заданий — экран «Миссия выполнена!», остров получает звезду, счётчик звёзд виден вверху слайда.
- Кнопка «Программа курса →» активна после первой пройденной игры.
- Прежняя практика (математика, английские карточки, Scratch-лабиринт, веб-студия, LMS) лежит нетронутой в скрытом блоке `.legacy-practice` внутри `#slide-5`: чтобы вернуть её, нужно убрать `hidden` и CSS-правило `#slide-5 .legacy-practice{display:none}`. Картинки этого блока не предзагружаются (`perf-prefetch.js`).
- Тесты: `node tests/island-game.cjs` (каждое задание решаемо, один верный ответ, ru/uz заполнены), `node tests/practice-regression.cjs`.
- Переходы: `JuniorFx.run(from, to, apply, forceMode)` — четвёртый параметр задаёт вариант (`fly`, `rise`, `wind`).
